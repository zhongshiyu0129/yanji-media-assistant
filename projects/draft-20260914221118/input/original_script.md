# 原始口播稿

## 标题

未命名口播稿

## 原文


清朝倒台以后，为什么这些满洲八大姓也跟着消失了呢？因为全都改了汉姓了呗，咱们就比如说这个钮祜禄氏，我们再看甄嬛传里边的这个甄嬛，它的全名就叫钮祜禄甄嬛，另外还有和珅，全名叫做钮祜禄，和珅。只不过后来钮祜禄大多改姓了郎，因为在蛮语里边呢，钮祜禄就是郎的意思，后来呢就取了谐音郎，弹钢琴的郎朗，还有打牌去的郎平，他们祖上呢都是属于钮祜禄氏，另外还有叶赫那拉氏，慈禧太后就是叶赫那拉氏，慈禧是她的徽号，她的闺名叫做姓甄，全名叶赫那拉姓甄。后来呢，叶赫那拉氏大都改姓了，那你像那英，他祖上呢就是叶赫那拉氏，还有瓜尔佳氏，我们说的这个鳌拜就是瓜尔佳氏，全名叫做瓜尔佳氏，鳌拜。后来瓜尔佳氏呢，大部分都改姓成了关姓，像关晓彤，关之琳这些祖上呢都是属于挂尔。
而加释就有很多人好奇说这个爱新觉罗是不是满洲八大姓呢？爱新觉罗还真不是，它是属于清朝皇室的姓氏，要比满洲八大姓还要高一个等级。爱新觉罗呢，在满语里边，意思是像金子般尊贵的觉罗家族。爱新觉罗后来改汉姓氏就取了一个金字。比如说现在娱乐圈里边的金巧巧，他呢，就是属于爱新觉罗氏，还有吴京，吴京虽然是不属于满洲八大姓，但确实是属于满洲八旗，吴京是正白旗，那英呢是正黄旗，而朗朗是镶黄旗，以前呢，这些明星们都是特别自豪自己的八旗身份，那是生怕别人不知道自己是八旗子弟，就是因为在清朝的时候呢，人家这个八旗子弟确实是妥妥的特权阶层，那是要比我们这些普通老百姓都要高贵很多的，有多高贵呢？这么说吧，八旗，贵州每天呢，最多的就是时间和钱到处都是有钱人家呀，人家大清国钉钉江山之后呢，这些八旗子弟那都是不用像我们这些牛马去上班的，不用工作的，到了点呢就来领钱领粮。那他们平时干点什么呢？就是玩呀，斗个蛐蛐了，去遛个鸟啊，再养个狗啊，什么的。那么这些八旗子弟凭什么就有如此高贵的特权呢？这个呢？就要从女真族的首领努尔哈赤那头开始讲了。当年努尔哈赤呢，带着部队统一了女真各部。后来呢，这支队伍是越打越多，为了方便管理，就建了八旗军。八旗军呢，分别是正黄旗，正白旗，正红旗，正蓝旗，镶黄旗，镶白旗，镶红旗镶蓝旗努尔哈赤死了之后呢，他的儿子多尔衮就带着八旗军打进了中原，建立了清朝。于是呢，这些八旗军的好日子就开始了，他们呢是跑马圈地，把原住民的土地全都圈给了自己，还把北京城内的汉人全都赶出了城外，然后让八旗人全部都住在了内城，我们看一下这张图啊，这个中间的位置呢，就是皇城周围住的都是八旗，这座城呢，有四座皇城门，9座内城门，那你们之前是不是经常听说老北京的这个四九城呢？四九城说的就是这个地方了，你像我们内蒙古现在的蒙旗制度，这个里边的旗呢，它的源头就是满洲八旗，就是当时清朝为了治理蒙古草原创立的一个军政合一的制度，仿八旗分部落编扎萨克会盟统管扎萨克的意思呢，就是执政王爷是旗的首领，像我们现在沿用下来的达拉特旗，以经霍洛旗，温牛特旗等等。想当年呢，这些八旗人在四九城，那可是过得神仙般的日子呀，对于咱们这些牛马汉人来说呢，那绝对是妥妥的特权阶层，这就是前些年为什么有的人一提到自己的这个八旗身份就特别的自豪的原因了。那么既然说这些八旗子弟如此的自觉高贵，为什么后来又自己四降身价，隐匿身份全都改了汉姓呢？原因也特别简单，那就是怕挨打。当年清朝在的时候，他们是特权阶层，但是清朝一倒，谁还认你的特权呀？旗人失去了俸禄，土地和特权可以说是一夜回到了解放前。而且如果说只是没有了特权，没有了俸禄，没有了土地，那旗人呢？或许还能接受。更要命的是，辛亥革命以后呢，就提出了这个驱除鞑虏，恢复中华的口号。这一下呢，就让这些旗人一夜之间成了过街老鼠。之前很多受到压迫的百姓就纷纷的出来，开始针对这些曾经的特权阶层展开报复，而且很多的旗人也因为怕被报复，这就开始改了汉姓。不过呢，这也只是一方面的原因。还有一个更重要的原因呢，就是为了方便寻求更好的出路。你说以前生活在内城的旗人，他们呢？除了吃喝玩乐，没有任何的生存技能，那现在这些铁饭碗被人砸了，那总不能坐吃山空等死吧。所以旗人呢，就开始不得不低下高傲的头颅出去经商打工，那改用汉姓呢，就可以更好的融入汉人，避免被区别对待。就这样呢，满洲八大姓也就慢慢的消失在了历史的洪流中。在以前呢，这些明星是生怕别人不知道自己祖上是八旗贵胄是特权阶层。但是现在呢，这些明星是生怕别人知道自己是八旗子弟，那又是什么让他们变得如此低调了呢？别无他因，就因为当年这个清朝的历史被扒了个底儿朝天而已。
