# Style Infusion

Goal: make the script sound like the user's account, with local ideas, cases, phrases, and memory.

## Inputs to read when present

- `materials/profile/account_profile.md`
- `materials/profile/writing_style.md`
- `materials/profile/prohibited_style.md`
- `materials/ideas/my观点.md`
- `materials/ideas/案例素材.md`
- `materials/ideas/金句库.md`
- `memory/content_memory.md`

## Rules

- Use short, spoken, direct sentences.
- Keep information density high.
- Add the user's judgment when supported by local materials.
- Add cases only if provided or clearly generic.
- Remove phrases forbidden by the profile or memory.
- For nostalgic topics, add shared life memory, generational change, or ordinary people's emotional entry point.
- Do not over-polish into formal essay language.

## Output file

Write `projects/<slug>/process/style_draft.md`.

Use this structure:

```markdown
# 05 风格融合稿

## 正文

## 使用的账号素材
- 账号定位：
- 写作风格：
- 用户观点：
- 案例素材：
- Memory：

## 风格调整说明
```
