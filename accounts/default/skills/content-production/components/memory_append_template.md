# Memory Append Template

Use this format when suggesting memory updates.

Do not append to long-term memory unless the user permits it.

```markdown
### YYYY-MM-DD 主题：[主题]
- 原稿问题：
- 本次策略：
- 有效开头：
- 有效结尾：
- 有效标题：
- 用户偏好：
- 风险处理：
- 避免表达：
- 用户反馈：
```

## Long-term memory sections

Append durable patterns to one of these sections in `memory/content_memory.md`:

- 账号长期风格
- 有效开头
- 有效结尾
- 有效标题模式
- 用户偏好
- 踩坑记录
- 修改历史
