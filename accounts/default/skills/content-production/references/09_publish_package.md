# Publish Package

Goal: create platform-ready titles, cover text, descriptions, tags, and a recommended combination.

## Titles

Create at least 8 titles:

- Question type.
- Contrast type.
- Result type.
- Cognitive reversal type.
- Nostalgic empathy type.
- Direct value type.

Rules:

- Attractive but not false.
- Supported by the script.
- Avoid irrelevant hot words.

## Cover text

Create 5 options:

- Prefer 6-14 Chinese characters.
- Direct, readable, and conflict-aware.
- One glance should reveal the topic.

## Description

Create 1-3 descriptions:

- First sentence must state the value directly.
- Open with the topic, not background.
- Can guide comments, saves, or shares, but not mechanically.

## Tags

Create 10-20 tags:

- Topic terms.
- Field terms.
- Audience terms.
- Emotion terms.
- Platform distribution terms.

## Output file

Write `projects/<slug>/process/publish_package.md`.

Use this structure:

```markdown
# 10 发布素材包

## 爆款标题

## 封面文案

## 视频描述

## Tags

## 推荐组合
```
