# Elevated Ending And Poem

Goal: create an emotional ending and a four-line rhymed poem suitable for spoken delivery.

## Ending rules

- Elevate from the specific topic to a broader emotional meaning.
- Use family-country feeling only when appropriate to the topic.
- For nostalgic topics, use concrete shared memory or era change.
- Avoid empty slogans.
- Be rigorous, rational, and restrained; do not incite emotions or create opposition.
- Let emotion grow from facts, ordinary life, and long-term values, not from exaggeration.
- Keep it spoken and recordable.

## Poem rules

- Four lines.
- Same or close rhyme preferred.
- Try to respect rhythm and tonal balance, but do not sacrifice clarity.
- Avoid rare characters.
- Do not let the poem overpower the script.

## Output file

Write `projects/<slug>/process/ending_poem.md`.

Use this structure:

```markdown

## 升华结尾

## 四句诗

## 押韵与口播说明
```
